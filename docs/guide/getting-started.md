# Быстрый старт

Это руководство поможет вам быстро запустить SHM и создать первую услугу.

## Предварительные требования

- Сервер с Linux (Ubuntu 20.04+ рекомендуется)
- Docker и Docker Compose
- Минимум 2 GB RAM, 20 GB диска

## Шаг 1: Установка

```bash
# Установите Docker (если ещё не установлен)
curl -sL https://get.docker.com | bash

# Создайте директорию для SHM
mkdir -p /opt/shm && cd /opt/shm

# Скачайте файлы конфигурации
curl -sO https://raw.githubusercontent.com/danuk/shm/master/docker-compose.yml
curl -sO https://raw.githubusercontent.com/danuk/shm/master/.env

# Запустите
docker compose up -d
```

## Шаг 2: Первый вход

Откройте в браузере: `http://ВАШ_СЕРВЕР:8081`

- **Логин:** `admin`
- **Пароль:** `admin`

::: danger Важно!
Сразу после первого входа смените пароль администратора!
:::

## Шаг 3: Создание услуги

1. Перейдите в раздел **Сервера** → **Группы**
2. Создайте новую группу серверов (например, "Subscription")
3. Перейдите в **Услуги** → **Каталог**
4. Создайте новую услугу:
   - Название: "Sub Basic"
   - Группа серверов: "Subscription"
   - Стоимость: 200
   - Период: 1 месяц

## Шаг 4: Настройка события

1. Перейдите в **Услуги** → **События**
3. Добавьте событие `CREATE`:
   - Группа серверов: "Subscription"
   - Шаблон или Команда: для создания аккаунта клиента

## Шаг 5: Регистрация клиента

1. Перейдите в **Пользователи**
2. Создайте нового пользователя
3. Перейдите в **Пользователи** → **Услуги пользователей**
4. Добавьте услугу пользователю

SHM автоматически выполнит команду из события `CREATE` на указанном сервере!

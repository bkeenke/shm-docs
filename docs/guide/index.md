# Что такое SHM?

SHM — это открытая, бесплатная универсальная биллинговая система с действиями по событиям.

## Принцип работы

1. **Создавайте услуги** — назначайте им цену, период действия и другие свойства
2. **Регистрируйте клиентов** — и оказывайте им услуги
3. **Автоматизируйте** — SHM выполнит назначенные [команды](/guide/setup/events) на ваших [cерверах](/guide/setup/servers) в зависимости от [событий](/guide/setup/events)

## Для чего подходит SHM?

SHM отлично подходит для оказания разовых и периодических услуг:

- 🖥️ Услуги хостинга
- 🛒 Продажа сервисов и подписок
- 🌐 Интернет услуги и услуги связи с безлимитными (пакетными) тарифами
- 📦 Любые услуги по подписке

::: warning
SHM не предназначен для учёта потребляемых услуг (трафик, минуты, звонки и т.п.)
:::

## Архитектура

SHM состоит из следующих компонентов:

- **Ядро системы (API)** — основная логика биллинга
- **База данных MySQL** — хранение всех данных
- **Личный кабинет администратора** — управление системой
- **Личный кабинет пользователя** — интерфейс для клиентов

## Быстрый старт

Самый простой способ начать — использовать Docker:

```bash
# Создайте рабочую директорию
mkdir -p /opt/shm && cd /opt/shm

# Скачайте конфигурацию
curl -sO https://raw.githubusercontent.com/danuk/shm/master/docker-compose.yml
curl -sO https://raw.githubusercontent.com/danuk/shm/master/.env

# Запустите SHM
docker compose up -d
```

После запуска SHM будет доступен по адресу: `http://localhost:8081`

**Логин:** `admin`
**Пароль:** `admin`

# Telegram бот

Telegram бот позволяет вашим клиентам управлять услугами прямо из мессенджера.

## Возможности

- 📋 Просмотр услуг и их статуса
- 💳 Пополнение баланса
- 🛒 Покупка новых услуг
- 📊 История платежей
- ⚙️ Получение конфигов (VPN и т.д.)

## Создание бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя и username бота
4. Сохраните полученный токен

## Настройка в SHM

1. Перейдите в **Настройки** → **Telegram Bot**
2. Введите токен бота
3. Укажите webhook URL: `https://bill.example.com/telegram/`

### Конфигурация

```json
{
  "token": "123456789:ABCdefGHIjklMNOpqrsTUVwxyz",
  "webhook_url": "https://bill.example.com/telegram/"
}
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы / регистрация |
| `/balance` | Текущий баланс |
| `/services` | Список услуг |
| `/pay` | Пополнить баланс |
| `/help` | Справка |

## Кастомизация

### Приветственное сообщение

Создайте шаблон `telegram_start`:

```
Добро пожаловать, [% user.name %]!

🆔 Ваш ID: [% user.id %]
💰 Баланс: [% user.balance %] руб.

Используйте меню для управления услугами.
```

### Кнопки меню

Настройте inline-клавиатуру в шаблоне:

```json
{
  "keyboard": [
    [{"text": "💰 Баланс", "callback_data": "balance"}],
    [{"text": "📋 Мои услуги", "callback_data": "services"}],
    [{"text": "🛒 Купить", "callback_data": "buy"}]
  ]
}
```

## Уведомления

Настройте автоматические уведомления клиентам:

- Успешная оплата
- Скоро истекает услуга
- Услуга заблокирована
- Новые промо-акции

### Пример шаблона уведомления

```
⚠️ Внимание!

Ваша услуга "[% us.name %]" истекает [% us.expire %].

Пополните баланс, чтобы услуга продолжала работать.

💰 Текущий баланс: [% user.balance %] руб.
```

## Привязка пользователей

При первом обращении к боту пользователь может:

1. **Зарегистрироваться** — создаётся новый аккаунт
2. **Привязать существующий** — ввести логин и пароль

## Отладка

Проверьте логи бота:

```bash
docker compose logs -f shm-core | grep telegram
```

# Серверы

Серверы в SHM — это машины, на которых выполняются команды событий.

## Типы подключения

SHM поддерживает несколько транспортов для подключения к серверам:

| Транспорт | Описание |
|-----------|----------|
| SSH | Выполнение команд через SSH |
| HTTP/API | HTTP запросы к API |
| Local | Команды на локальной машине |
| Telegram | Отправка сообщений |
| Mail | Отправка email |

## Добавление сервера

1. Перейдите в **Настройки** → **Серверы**
2. Нажмите **Добавить сервер**
3. Заполните параметры:

### SSH сервер

```yaml
name: "VPN Server 1"
transport: ssh
host: 192.168.1.100
port: 22
user: root
auth: key  # или password
```

### HTTP API

```yaml
name: "Marzban API"
transport: http
url: https://marzban.example.com/api
headers:
  Authorization: "Bearer YOUR_TOKEN"
```

## Настройка SSH

### Авторизация по ключу (рекомендуется)

1. Сгенерируйте ключ на сервере SHM:
```bash
docker exec -it shm-core ssh-keygen -t ed25519
```

2. Скопируйте публичный ключ на целевой сервер:
```bash
docker exec -it shm-core cat ~/.ssh/id_ed25519.pub
```

3. Добавьте ключ в `~/.ssh/authorized_keys` на целевом сервере

### Авторизация по паролю

::: warning Внимание
Авторизация по паролю менее безопасна. Используйте SSH ключи когда возможно.
:::

## Проверка подключения

После добавления сервера проверьте подключение:

1. Откройте сервер
2. Нажмите **Проверить подключение**
3. Убедитесь, что статус "Подключено"

## Группы серверов

Серверы можно группировать для удобства:

- По типу (VPN, Web, Mail)
- По локации (EU, US, Asia)
- По проекту

## Балансировка нагрузки

При создании услуги можно указать группу серверов — SHM автоматически распределит пользователей между серверами группы.
